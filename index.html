Real vs Simulated System Architecture

REAL (Actual Hardware/Execution):
  • WebAssembly bit-level processing (C binary compiled to WASM)
  • Live bit calculations (CRC-8 0x07, Hamming(7,4) syndromic decode)
  • Actual audio output synthesized via Web Audio API
  • Real measured ping and download speed tests (Network Lab)
  • Actual keyboard DOM events & ASCII codes (Basics Lab)
SIMULATED (Software Models):
  • Wireless/Cable channel noise (Software AWGN via Box-Muller)
  • RF carrier propagation (Discrete 20-sample digital DSP model)
  • Layer-2 LAN Switch MAC address learning animation
  • Login session (Client demo mode)
